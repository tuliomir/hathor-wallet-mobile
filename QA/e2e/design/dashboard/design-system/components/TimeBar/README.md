# TimeBar

Elapsed against expected for the current step or scenario, with room to run past 100%.

## Guidelines

- The track spans 150% of the estimate; the tick marks 100%, so overrun is visible as length, not just a number.
- Past 100% the fill turns amber and the caption adds the ratio (`4.0×`). Stuck is decided by events, not by this bar.
- Times are `m:ss`, tabular.

Props: see `index.d.ts` (`TimeBarProps`).
