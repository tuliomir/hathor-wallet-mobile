# ScenarioId

A long dotted scenario id split into its axis values so it can be scanned.

## Guidelines

- Drops the `action:fixture:` prefix (kept in the title).
- Dots are faint; the trailing wallet value is dim; values passed in `highlight` turn link-blue — use it for the axes that differ from the previous row or that the person filtered on.
- Monospace, wraps at the dots on phone.

Props: see `index.d.ts` (`ScenarioIdProps`).
