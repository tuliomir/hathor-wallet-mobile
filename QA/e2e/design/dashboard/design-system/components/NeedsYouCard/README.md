# NeedsYouCard

One thing the person must do now, with the exact command to copy.

## Guidelines

- Shown at the top, under the header, only when something applies: the part ended and waits for a resume, a job has failures, it looks stuck, a job didn't finish.
- Amber, not red: it asks, it doesn't alarm. A failure's own panel carries the red.
- One line on what to do, then the command. The page never runs it.
- With nothing to do, render it without a title: a quiet dashed strip that says when the next thing will be.
