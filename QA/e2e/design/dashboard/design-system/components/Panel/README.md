# Panel

The section card every block of the page sits in.

## Guidelines

- `surface-1` on `surface-0`, a `line` hairline, `radius-lg`, padding `space-5` (`space-4` on phone). No shadows.
- Starts with an eyebrow label in capitals; the label also names the region for screen readers.
- One answer per panel, in `figure-xl`, then its explanation in `small`.

Props: see `index.d.ts` (`PanelProps`).
